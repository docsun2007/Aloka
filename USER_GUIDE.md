# 快速使用 / Quick start

1. 为样品命名，将重复测量的 TXT 放到所属样品下。检查数据，确认实验结构。 / Name the samples, add each sample’s replicate TXT files, check the data and confirm the structure.
2. 设定区间、平滑与基线并分析。检查实验谱、分峰、总拟合、残差和诊断。 / Set the range, smoothing and baseline, run analysis and inspect the curves, residuals and diagnostics.
3. 在 Raman 图打开专业编辑。拖动先改变候选预览。需要时锁定并重新优化，再确认新版本。 / Open the peak editor from the Raman plot. Dragging previews a candidate. Lock and refit as needed, then confirm a new version.
4. 保存 .raman，按需导出 XLSX 或 OPJU。自定义图组要核对样品顺序与版本。 / Save .raman and export XLSX or OPJU as needed. Check sample order and result versions in custom figure groups.
5. 重开保存的 .raman，核对样品与版本后再继续编辑。 / Reopen the saved .raman file and review samples and versions before editing.
