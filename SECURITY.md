# 安全问题反馈 / Security reporting

目前没有公开可下载的发行版。普通使用问题可提交到 [GitHub Issues](https://github.com/docsun2007/Aloka/issues)。

若涉及漏洞、隐私或未发表数据，请先通过已有的私下渠道联系维护者。请勿在公开 Issue 中附真实工程、带账户名的路径、凭据、完整日志或漏洞利用细节。

There is no public downloadable release. Use GitHub Issues for ordinary feedback. For security or privacy concerns, contact the maintainer privately through an existing channel. Keep credentials, unpublished data, private paths and exploit details out of public reports.
